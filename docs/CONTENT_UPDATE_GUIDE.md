## 2. 全站视觉基线

### 2.1 颜色

主基调：

- 米白背景；
- 黑色正文；
- 暖灰次级文字；
- 少量强调色仅用于状态、视觉节奏或历史设计元素。

原则：不要为了“丰富”而增加大量色块。SCU LENS 的主体始终应是照片与排版。

### 2.2 字体分层

当前采用三层字体语义：

1. **无衬线字体**
   - 正文；
   - 导航；
   - 功能性标题；
   - 活动名、部门名、状态标题。

2. **中文衬线 / 宋体方向**
   - 杂志感章节标题；
   - 需要拉开层级但不靠超大字号解决的标题。

3. **英文字体 / Georgia 类**
   - SCU LENS 品牌字；
   - 少量拉丁字符标题；
   - 英文视觉点缀。

英文 Eyebrow 一律保持小字号、大字距、全大写风格；不要和中文标题争视觉。

### 2.3 字号层级

不要用“不断放大”制造层级。当前规则：

- 页面一级大标题：全站统一一档；
- section 标题：明显小于页面一级标题；
- 具体活动名 / 卡片主标题：优先于分类名；
- 正文：统一 body 字号；
- 英文 Eyebrow / 日期 / tag：统一小字号。

如果一页同时出现多个大标题，应优先降级“分类标题”，让真正的内容名成为主角。

## 3. 间距规则

### 3.1 页面顶部

除首页 Hero 外，一级内容页统一：

- 顶部导航下方的正文起点使用同一套 page top spacing；
- Desktop：左侧 `Eyebrow + 中文大标题`，右侧说明文字；
- 中文大标题与右侧说明文字底部对齐；
- Mobile：自然折成单栏，不强行保留双栏。

不要再给单独页面写一套明显不同的顶部留白。

### 3.2 section 上下间距

当前 section 已统一成“上方分界线 → 内容”和“内容 → 下方分界线”都较紧凑的节奏。

原则：

- 不留两三行空白；
- 标题和正文之间只保留必要呼吸；
- 分界线用于组织结构，不要靠大空白隔断；
- 手机端比桌面端更紧凑。

### 3.3 2×2 信息块

“关于摄协”“在摄协里会经历什么”等 2×2 内容块采用杂志分栏逻辑，不做独立白色卡片。

结构：

```text
01
标题
说明
```

规则：

- 仅用细分隔线；
- 背景透明；
- 内容从左上向下排列；
- 不做垂直居中；
- 不留大面积空白；
- Mobile 改为单列。

## 4. 首页应该放什么

首页职责是“快速认识 SCU LENS + 当前最重要入口”，不是把所有内容全部展开。

当前顺序：

1. Hero / 品牌主视觉；
2. 每月九图；
3. 精选作品分类；
4. 活动动态状态；
5. 加入我们 / 联系与联动；
6. Manifesto；
7. Footer。

### 4.1 首页作品

首页只展示作品分类前四项：

1. 校园；
2. 人文；
3. 城市；
4. 自然。

完整作品页仍保留六类：

```text
校园 / 人文 / 城市 / 自然 / 人像 / 动物
```

首页不需要把六类全部铺满。

### 4.2 首页活动两张卡

首页活动区不是“长期活动 / 近期活动”分类展示，而是两个**当前状态入口**。

#### 左卡：当前最重要事件

默认：

- 当前正在发生或即将发生的具体活动；
- 例如“百团大战与新一轮招新”。

特殊状态：

- 每月九图刚完成评选并公布结果时；
- 左卡短期切成“本期结果公布”；
- 背景图改为当期入选作品；
- 点击整卡直接进入对应图集；
- 一段时间后恢复近期活动。

#### 右卡：每月九图当前状态

状态 A：主题准备中

```text
新一轮主题正在准备中
```

- 不显示“前往投稿”小链接；
- 点击整卡进入活动页中的每月九图状态区。

状态 B：征集中

```text
主题名
正在征集中
```

- 右下增加独立“前往投稿”链接；
- 整卡仍然进入活动页状态区；
- 小链接单独进入投稿页。

## 5. 每月九图更新规则

### 5.1 新主题尚未公布

- 首页右卡：显示“新一轮主题正在准备中”；
- 活动页：同步显示 PREPARING 状态；
- 不出现投稿快捷入口。

### 5.2 新主题开始征集

需要同步更新：

1. 首页右卡：主题名 + 正在征集中；
2. 首页右卡右下：前往投稿；
3. 活动页“每月九图状态”；
4. 投稿页专项征集提示；
5. QQ 频道继续作为真实投稿入口。

### 5.3 评选结果公布

需要同步更新：

1. 新建 / 更新对应期详情页；
2. 接入作品与作者信息；
3. 首页左卡可短期变成结果公布卡；
4. 首页右卡回到“下一轮准备中”或新一轮征集状态；
5. 活动页状态同步；
6. 总览页将最新一期放在最上方。

### 5.4 每月九图内容层级

```text
/monthly-nine
  → 单期详情
    → 多图作品详情（如有）
```

- 总览：摘要、状态、代表图；
- 单期：完整主题文案、结果与入选作品；
- 多图作品：完整组图；
- 真实图片保留原始比例；
- 总览预览图可以裁切，详情页不随意裁切原图。

## 6. 作品分类更新规则

当前固定顺序：

```text
校园 → 人文 → 城市 → 自然 → 人像 → 动物
```

英文：

```text
CAMPUS / HUMANITY / URBAN / NATURE / PORTRAIT / ANIMALS
```

分类是长期母分类。

不要把：

- 春日；
- 新春；
- 江安青绿；
- 夜色；

这类季节 / 专题名称混入作品母分类。

它们应作为：

- 每月九图主题；
- 专题；
- 标签；
- 地点或季节元数据。

## 7. 活动页更新规则

活动页当前结构：

1. 近期活动；
2. 每月九图状态；
3. 日常投稿与作品收录（并入状态区，不单独做大 section）；
4. 过去记录。

活动页原则：

- 具体活动名称是主角；
- “近期 / 招新 / 归档”只做辅助 tag；
- 不用超大分类标题压过活动名；
- 活动结束后，条目从“通知”自然沉淀成档案。

更新活动时至少记录：

- 时间；
- 活动名；
- 一句话说明；
- 状态 / tag；
- 后续如有照片，再补活动档案。

## 11. 内容更新优先级

日常维护时按以下顺序判断：

### 最高优先级

- 当前活动；
- 每月九图状态；
- 最新一期每月九图；
- 招新状态；
- 联系方式。

### 中优先级

- 新作品分类收录；
- 活动回顾；
- 作者信息；
- 关于页文字。

### 低优先级

- 装饰动效；
- 非必要视觉花活；
- 为了“填满页面”增加的冗余内容。

## 12. 修改前检查

每次改 UI 前先问：

1. 这是页面主内容，还是分类说明？
2. 标题是不是大过了真正的内容？
3. 是否出现两三行无意义空白？
4. 是否为了好看又造了大卡片？
5. Desktop / iPad / Mobile 是否都能成立？
6. 新内容是否应该进入首页，还是只进入详情页？
